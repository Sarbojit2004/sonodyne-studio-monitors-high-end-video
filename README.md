# Sonodyne SRP / SLF — 88-Second Vertical Reel

A 1080×1920, 30fps, **88.000s (2,640 frame)** Remotion reel covering the Sonodyne
**SRP 350 G**, **SRP 400 G**, **SRP 501 G**, **SRP 601 G** studio monitors and the
**SLF 210 V3** active subwoofer, for **Shivansh Electronics**.

Source photography, the two logo files and the creative brief live at the repo root.

---

## Quick start

```bash
npm install
python3 scripts/build_timeline.py      # timeline.json  (visual cuts + SFX cues)
python3 scripts/classify_images.py     # bg-class.json  (white / grey / dark per image)
python3 scripts/measure_type.py        # archivo-metrics.json (real advance widths)
python3 scripts/gen_audio.py           # synthesize every sound
npm run studio                         # preview
npm run render                         # out/sonodyne-reel-88s.mp4
```

Thumbnails:

```bash
npx remotion still ThumbnailEnglish thumbnails/thumbnail-sonodyne-reel-english.png
npx remotion still ThumbnailHindi   thumbnails/thumbnail-sonodyne-reel-hindi.png
npx remotion still ThumbnailBengali thumbnails/thumbnail-sonodyne-reel-bengali.png
```

> This environment blocks `remotion.media`, so Remotion cannot download its own
> Chrome Headless Shell. `remotion.config.ts` points it at the Chromium already on
> the image; override with `REMOTION_BROWSER=/path/to/chrome` elsewhere.

## Design constraints this build is engineered around

### Light background, everywhere
The page ground is a warm light neutral (`#F4F2EE`) in **every frame**. This is a
deliberate reversal of the creative brief's own Section 6, which calls for "deep
greys, charcoals and abyssal blacks".

Because 26 of the source photos are dark studio/lifestyle frames, they are **never**
used full-bleed — they are framed as inset panels, so the page stays light while the
photograph stays dark. The 34 pure-white pack shots sit on a white card and read as
the product floating on the page.

Text is dark ink on light, the inverse of a dark-background build. Measured contrast:

| role | colour | on paper | on card |
|---|---|---|---|
| headline | `#101317` | 16.66:1 | 18.62:1 |
| body | `#454B53` | 7.88:1 | 8.81:1 |
| micro | `#5F666F` | 5.19:1 | 5.81:1 |
| accent | `#A84E17` | 4.99:1 | 5.57:1 |

### Instagram safe-zone geometry
| zone | pixels | rule |
|---|---|---|
| top | 0–250 | ambient/decorative only |
| **primary content** | **250–1580** | everything the viewer must read |
| bottom | 1580–1920 | ambient/decorative only |
| side margins | 80px each | all text and critical detail inboard |

The top and bottom bands are never empty (Section 2b): they carry blurred,
desaturated, lightened ambient-tier photography, either a dedicated ambient image or
a soft echo of the current hero shot.

### Every image appears
All **68** product/context images in the repo are placed — 58 in the primary/hero tier
inside the safe zone, 10 in the ambient band tier. `scripts/verify_coverage.py` proves
the bijection and fails the build if any image is unplaced.

## Architecture

`src/data/timeline.json` is the **single source of truth**. It is generated by
`scripts/build_timeline.py` and read by *both* the React scenes and the Python audio
synthesizer, so a visual cut and its SFX cue cannot drift apart.

```
src/
  theme.ts              palette, type scale, safe-zone geometry, elevation
  Reel.tsx              composition root: scenes + 4 audio tracks
  Thumbnail.tsx         1080x1920 thumbnail, one design x 3 language badges
  data/
    timeline.json       beats, shots, ambient bands, 67 SFX cues   <- generated
    products.ts         VERIFIED specs + prices + contact details
    copy.ts             every on-screen string
    bg-class.json       per-image background tone                   <- generated
    archivo-metrics.json real font advance widths                   <- generated
  components/           Stage, AmbientBands, Photo, ShotStage, Type, BeatText,
                        BottomRail, Overlays
  scenes/               ShotScene (hook/DNA/products/system), Pricing, CTA
scripts/
  build_timeline.py     writes timeline.json
  classify_images.py    writes bg-class.json
  measure_type.py       writes archivo-metrics.json
  gen_audio.py          synthesizes all audio
  dsp.py                original DSP toolkit (oscillators, filters, reverb)
  verify_coverage.py    every image placed?
  verify_audio.py       audio real, correct length, cues on the cut frames?
  qa_stills.py          pixel-level safe-zone + light-background checks
```

### Typography
Display and body are **Archivo Variable** (weight + width axes); spec numerals are
**JetBrains Mono Variable**.

Two hard constraints, verified against the actual `woff2` files:

- **JetBrains Mono ships no rupee glyph in any subset.** Prices are therefore *always*
  set in Archivo. Setting a price in mono would render tofu.
- **Archivo has no `U+2192`.** There is no literal arrow character anywhere; arrows are
  drawn as SVG.

Headlines are `nowrap`, so `scripts/measure_type.py` instantiates the variable font at
the display instance (`wght 800`, `wdth 118`) and exports real advance widths. The
`Headline` component uses them to shrink any line that would otherwise run past the
side margin — this caught `IN YOUR ROOM.` at 104px measuring 968px against a 920px box.

> **Note:** Section 6a of the brief asks for the type system to be ported from
> `Sarbojit2004/motu-ultralitemk5-828`. That repo is not attached to this session and
> the GitHub proxy refuses it (403), with no `add_repo` tool available here, so it could
> not be read. The pairing above is a documented substitute, isolated in `src/theme.ts`
> so swapping in the real MOTU system is a single-file change.

### Audio — all synthesized, no external service
Nothing is sampled, downloaded, or generated by ElevenLabs or any other audio service.
`scripts/dsp.py` is an original toolkit (oscillators, shaped noise, state-variable and
sweeping band-pass filters, convolution reverb against a synthetic tail, saturation,
constant-power panning). `scripts/gen_audio.py` builds:

| track | level | role |
|---|---|---|
| `ambient-bed.wav` | −30 dBFS rms | continuous 88s texture, never silent |
| `sfx-cues.wav` | peak 0.99 | 67 cues placed on the exact cut frames |
| `music-bed.wav` | −20 dBFS rms | original score, 120 BPM, A minor |
| `vo/voiceover-reel-sonodyne.wav` | silent | 88.000s placeholder for the VO |

The 13-cue palette (`impact-deep`, `whoosh-low`, `tick-triple`, `stepper`,
`chime-stack`, `sub-drop`, `transition-sweep`, …) is deliberately varied so dozens of
transitions never read as the same whoosh repeating. SFX are mixed hot on purpose —
final balance against the recorded voiceover is a post decision.

The score follows the brief's Section 10: dry clinical percussion → widening pads at
bar 22 → clean sub-bass foundation from bar 31 (~62s), landing with the SLF 210 V3 beat.

## Content rules enforced throughout

- **No other audio brand** is named, compared to, or implied — anywhere.
- **No distributor / dealer / reseller / "authorised" language.** Shivansh Electronics
  is presented purely as where to buy, ask and get the best price.
- **No tagline.**
- **No logo files.** Neither `SONODYNE BRAND LOGO.png` nor
  `SHIVANSH ELECTRONICS BRAND LOGO.png` appears in the video or the thumbnails — those
  are added by hand afterwards. Where a *photograph* already carries a printed Sonodyne
  badge, it is left exactly as shot.
- **Verified specs only.** Every number traces to the VERIFIED master table in the
  brief. The legacy "Kevlar" cone attribution for the 501/601 is not used; the brief
  resolves those to Glass Fibre.
- **No burned-in captions.** The reel carries no on-screen typography of spoken words.

## Validation

```bash
python3 scripts/verify_coverage.py   # all 68 images placed
python3 scripts/verify_audio.py      # audio real, right length, cues on the cuts
./node_modules/.bin/tsc --noEmit     # typecheck
npx remotion bundle                  # bundler check
python3 scripts/qa_stills.py         # 44 stills, pixel-level layout checks
```

`qa_stills.py` is the interesting one. It renders a still inside every shot and asserts,
on the actual pixels, that:

1. no pixel darker than luma 95 (i.e. ink — text, rules, hard-edged graphics) appears in
   the top band, bottom band, or either side margin;
2. the frame's mean luminance stays high and neither band goes dark, so the background
   is genuinely light throughout;
3. neither band is flat empty paper.

This caught two real defects that reviewing by eye did not: a headline overflowing the
right margin, and the SLF's 35Hz response curve drawing its knee into the left margin.

## Voiceover

`VO_SCRIPT_REEL_SONODYNE.md` — one continuous Hindi/English/Bengali blended script
timed to 88s (~209 words, ~142 wpm). All numbers are digits; Hindi and Bengali are
transliterated into Latin script; technical terms stay in English.

Record at exactly 88.000s and replace `public/vo/voiceover-reel-sonodyne.wav`.
