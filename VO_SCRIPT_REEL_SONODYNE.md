# Voiceover Script — Sonodyne 88-Second Reel

**Runtime:** 88.000s exactly (2,640 frames @ 30fps)
**Format:** one continuous trilingual narration — Hindi, English and Bengali blended
inside the same sentences, not three separate language versions.
**Placeholder track:** `public/vo/voiceover-reel-sonodyne.wav` (88.000s of silence,
already wired into the composition — drop the recorded read in at the same length).

---

## Rules this script follows

1. **One blended script.** Hindi, English and Bengali code-switch mid-sentence, the way
   this audience actually speaks. There is no separate Hindi cut or Bengali cut.
2. **Technical vocabulary stays in English.** Product names, model numbers, spec units
   and audio terms (`waveguide`, `bi-amplification`, `bass management`, `midrange`,
   `transient`, `Class AB`, `Class D`) are never translated — a vernacular substitute
   would read as wrong to anyone who works in a studio.
3. **Every number is written as digits**, in all three languages — `15W`, `58Hz`,
   `0.75dB`, `107dB`, `25,000`, `2.1`, `4`. Nothing is spelled out as a word.
4. **Hindi and Bengali are transliterated into Latin script.** No Devanagari, no Bengali
   script — this is a working read-aloud document, not display text.
5. **No other audio brand is named or implied.** No comparison of any kind.
6. **No distributor / dealer / reseller / "authorised" language.** Shivansh Electronics is
   simply where you buy, ask and get the best price.
7. **No tagline.**
8. **Not captions.** None of this text is burned into the video — the reel carries no
   on-screen typography of the spoken words.

## Delivery notes

- **Tone:** blend the brief's "Precise & Technical-but-Accessible" register with a warm
  close — an engineer explaining kit to a peer, not an announcer selling.
- **Pace:** ~209 words across 88s ≈ **142 wpm**, comfortably inside the 140–160 band.
  If a take lands past ~170 wpm the read is rushing; the spec lines are where it usually
  slips, so let the numbers breathe.
- **Numbers:** read naturally in context — "15W plus 15W" as *fifteen watts plus fifteen
  watts*, "0.75dB" as *point seven five dB*, "25,000" as *pachees hazaar*, "2.1" as
  *two point one*. They are written as digits so the reader can never mis-transcribe them.
- **Code-switching:** do not "announce" the language changes. The switch should sound
  incidental, the way it does in conversation.
- **Pronunciation:** *Sonodyne* — SON-oh-dyne. *CURV* — say the letters as a word, "curv".
  *SLF 210 V3* — "S-L-F two-ten V-three".
- **Beat alignment:** each timestamp matches a visual beat in `src/data/timeline.json`.
  The first product word lands with that product's hero shot; the price at the end of each
  product block lands while the bottom rail is still showing that price.
- **Recording length:** deliver at exactly 88.000s and replace
  `public/vo/voiceover-reel-sonodyne.wav`. If the file is a different length, re-run
  `npx remotion render` after trimming — the composition does not stretch audio.
