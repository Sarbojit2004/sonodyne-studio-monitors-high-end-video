# Sonodyne Long-Form Video (298 seconds)

A 1920×1080 landscape, 30fps, **298.000s (8,940 frame)** Remotion video covering all
five products in genuine chapter-by-chapter depth, for **Shivansh Electronics**.

This is the extended treatment of the same identity the companion [88-second
reel](README.md) establishes — same light background palette, same
per-product accent colors, same synthesized SFX design, same overlay-graphic
vocabulary (rigidity grid, directivity cone, EQ steps, phase dial, crossover
flow, all reused directly from `src/components/Overlays.tsx`) — deepened for
a landscape, no-reserved-zone, five-minute format with two hard reversals
from the reel's own defaults: **both logo files appear constantly** (the reel
excludes them entirely), and **typography is BarlowCondensed + Inter**,
inherited literally from the MOTU UltraLite-mk5/828 project's own long-form
build (the reel uses Archivo + JetBrains Mono, a substitute used only because
the MOTU repo was unreachable when the reel was built).

## Architecture

`src/lf/timeline-lf.json` is the single source of truth (generated by
`scripts/build_timeline_lf.py`), read by both the React scenes and the Python
audio synthesizer — same pattern as the reel's `timeline.json`.

```

  lf-theme.ts        chapter table, palette re-export, type scale
  fonts.ts            BarlowCondensed + Inter loader (FontFace API, MOTU pattern)
  LFType.tsx           Kicker/Headline/Sub/Price/Label, BarlowCondensed auto-fit
  LFFrame.tsx           light paper background (no reserved caption zone)
  LFShotStage.tsx        landscape layout engine: full/hero/split/duo/triad/quad/montage
  LFBeatText.tsx          text column renderer
  LFBrandBar.tsx           persistent rotating Shivansh Electronics corner strip
  LFLogoCard.tsx            light-plate logo card (both logos are dark-on-transparent)
  LFChapterScene.tsx         generic renderer: cold open, DNA, 5 products, system, workflows, heritage
  LFPricingScene.tsx          bespoke: 5-row price table
  LFOutroScene.tsx             bespoke: both logos, full contact block, family grid
  LFThumbnail.tsx               1920x1080 thumbnail, 3 language variants
  copy-lf.ts                    every on-screen string
  timeline-lf.json               generated: chapters, shots, SFX cues
  bc-metrics.json                 generated: BarlowCondensed real advance widths
scripts/
  build_timeline_lf.py     writes timeline-lf.json
  measure_type_lf.py        writes bc-metrics.json
  gen_audio_lf.py             extends the reel's SFX palette to 298s
  verify_coverage_lf.py        68/68 images placed exactly once

  package_zip.py                     reproducible offline project zip
```

### Typography — MOTU's actual files, one real glyph-coverage fix

Section 7a requires porting the literal MOTU UltraLite-mk5/828 type system,
not a substitute. MOTU's own long-form (`lf-theme.ts` in that repo)
deliberately uses **two faces** — BarlowCondensed (600/700/800, vendored
`.woff2`) for display, Inter (variable) for label/body/numerals — dropping
the third mono face its own *reel* uses. This build follows that same
long-form-specific precedent.

One fix was necessary: MOTU's vendored `inter-var.woff2` is subsetted to the
characters their own project used, and **has no rupee glyph** — MOTU never
priced anything in INR, this project prices everything in ₹. `inter-var.woff2`
here is the `latin-ext` build of the same Inter family (via
`@fontsource-variable/inter`, same fix pattern the reel used for Archivo) —
full glyph coverage, not a different font. BarlowCondensed is untouched
(MOTU's literal file; headlines never carry a price).

Headlines and kickers are set `white-space` constrained with real measured
advance widths (`scripts/measure_type_lf.py` instantiates the actual static
font and reads horizontal metrics) so nothing can silently overflow the text
column into the image zone — this caught two real bugs during build: a
44-character kicker overflowing into the photo, and (separately) a persistent
brand-bar label rendering illegibly over a dark full-bleed photo before it got
its own light plate backing.

### Logos — light plate, not MOTU's dark plate

Both logo files were pixel-sampled (not assumed): Sonodyne is a blue wordmark,
Shivansh Electronics a black wordmark, both dark-on-transparent — the natural
fit for this project's light background. `LFLogoCard` therefore uses a light
plate (matching the reel's own card language), the *inverse* of MOTU's own
`LogoCard.tsx`, which uses a dark plate because MOTU's marks are light-on-
transparent for its dark canvas. Same structural component, opposite polarity,
dictated by the actual asset, not assumed.

### Montage mode — one real design fix

The first version of the "efficient coverage" montage mode (Section 5) packed
all of a chapter's secondary lifestyle images into simultaneous narrow
vertical strips (as few as ~150px wide against a 1200×800 source). At that
aspect the crop lost the product entirely, showing unrecognizable slivers of
laptop-screen content instead of the speaker. It was rebuilt to show one
full-frame image at a time, cycling every 1.5–3s with progress dots — still a
rapid coverage pass, but every image stays actually recognizable.

### Audio — extends the reel's own synthesized palette

`scripts/gen_audio_lf.py` imports `scripts/gen_audio.py`'s `PALETTE` directly
rather than rebuilding it — the same 13 originally-synthesized SFX (no
ElevenLabs, no external service) that the reel already validated, re-used at
298s scale. A fresh continuous ambient bed and an original ~112 BPM score
follow the brief's Section 10 direction (clinical dry percussion → wider pads
→ clean sub-bass foundation), with the sub-bass climax locked to land exactly
at the SLF 210 V3 chapter (frame 4500 / 150.0s).

## Branding cadence (Section 9 — reversed from the reel's no-logo default)

A persistent rotating Shivansh Electronics corner strip (`LFBrandBar`,
structurally adapted from MOTU's own `LFBrandBar.tsx`) runs continuously from
frame 0 to the outro's own dedicated contact wall (frame 8280 / 276.0s),
rotating a new contact detail every 7 seconds — the maximum possible gap in
Shivansh Electronics' on-screen presence is its own ~0.5s crossfade, nowhere
near the ~25-30s guideline. Every product chapter additionally carries a
dedicated "Available at Shivansh Electronics — [price]" micro-line on its
closing beat.

Sonodyne appears at a deliberately lower frequency: the physical badge printed
on every product's cabinet (passive, continuous), plus three dedicated logo
moments — the Shared DNA chapter (its own engineering story), mid-video during
the SRP 501 G chapter, and paired with the Shivansh logo in the outro. Run
`python3 scripts/branding_audit_lf.py` for the full timestamped audit.
